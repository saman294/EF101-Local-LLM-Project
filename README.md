# EF-101 Local Large Language Model Hosting and Evaluation System

## Project Overview
This project implements a locally hosted Large Language Model (LLM) system using Ollama and Streamlit.

It allows users to interact with different AI models without relying on cloud-based LLM APIs.

## Technologies Used
- Python
- Streamlit
- Ollama
- Llama 3.2 (1B)
- Qwen 2.5 (1.5B)
- Requests
- JSONL

## Features
- Local AI chatbot
- Multiple model selection
- Prompt templates
- Conversation management
- JSONL conversation logging
- Model performance evaluation

## Installation

1. Install Python.
2. Install Ollama.
3. Download the required models.
4. Install dependencies:

```bash
pip install -r requirements.txt
```

## Run the Project

```bash
streamlit run app.py
```
